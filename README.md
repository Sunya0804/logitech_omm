# Onboard Memory Manager (Web)

Logitech G 마우스의 온보드 메모리 프로필을 브라우저에서 읽고 수정하는 정적 웹앱입니다.
WebHID로 기기와 직접 HID++ 2.0(기능 `0x8100` Onboard Profiles) 통신을 하며, 빌드나 서버 측 코드가 없습니다.

## 실행

WebHID를 지원하는 데스크톱 Chrome / Edge / Opera가 필요합니다.

설치 없이 <https://sunya0804.github.io/logitech_omm/> 에서 바로 쓸 수 있습니다. 직접 띄우려면 이 폴더에서:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

그다음 <http://127.0.0.1:8765> 을 엽니다.

G HUB나 공식 OMM이 실행 중이면 HID++ 통신이 충돌할 수 있으니 먼저 종료하세요.

## 기능

- 프로필 읽기, 사용/사용 안 함 전환, 활성 프로필 전환, 온보드/호스트 모드 전환
- 프로필 이름, 보고율, DPI 단계(최대 5개)·기본 단계·시프트 단계 편집
- 아날로그 버튼(작동점, 래피드 트리거, 클릭 햅틱) 편집 — 형식 8, 실기기 미확인
- 버튼 할당(기본 / G-Shift): 마우스 버튼, 키보드 단축키, 미디어 키, 특수 기능, 사용 안 함
- 프로필 백업 내보내기 / 불러오기 (JSON)
- 진단 정보 내보내기: 기능 목록과 온보드 메모리 전체를 읽기 전용으로 덤프 (새 기기 지원용)

조명(LED)과 매크로 편집은 지원하지 않으며, 기존 값은 그대로 보존됩니다.

## 프로필 형식

| 형식 | 구조 | 실기기 확인 | 비고 |
| --- | --- | --- | --- |
| 1~5 | 기본 (`classic`) | PRO X Wireless (4), G502 X PLUS (5) | |
| 6~7 | 확장 (`extended`) | PRO X 2 DEX (7) | 보고율이 무선/유선 따로(최대 8000 Hz), DPI 단계가 X/Y/리프트오프 거리 |
| 8 | 확장 + 아날로그 버튼 (`analog`) | 없음 | PRO X2 SUPERSTRIKE. 버튼별 작동점·래피드 트리거·클릭 햅틱 |
| 10 | 기본 + 세로 DPI (`classicDpiY`) | 없음 | 펌웨어 업데이트 이후의 G502 X 계열. 보고율은 편집하지 않음 |
| 그 외 | 데이터로 자동 판별 | 없음 | |

형식별 필드 위치는 공식 Onboard Memory Manager 2.7과 대조했습니다. 실기기로 확인하지 못한 형식은 경고에 동의해야 편집할 수 있습니다.
아날로그 버튼 값의 허용 범위는 기기가 정하는데(HID++ `0x1B0C`) 아직 읽어 오지 못해, 저장 가능한 최대치(0~63)까지만 제한합니다.

## 안전장치

- 편집은 메모리 상에서만 이뤄지고 「기기에 저장」을 눌러야 기록됩니다.
- 기기에서 CRC가 맞는 섹터를 하나라도 읽어야 쓰기가 허용됩니다.
- 섹터를 쓴 뒤 다시 읽어 내용을 대조합니다.
- 실기기로 확인한 프로필 형식(1~5, 7) 외에는 사용자가 명시적으로 허용해야 편집할 수 있고, 데이터가 알려진 구조로 읽히지 않으면 편집이 막힙니다.
- 알지 못하는 필드는 건드리지 않고 원본 바이트를 그대로 다시 씁니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `js/hidpp.js` | WebHID 전송 계층, HID++ 2.0 요청/응답, 온보드 프로필 명령 |
| `js/profile.js` | 프로필 섹터 바이너리 해석/수정, CRC, 프로필 디렉터리 |
| `js/keys.js` | 키·버튼·특수 기능 이름표 |
| `js/mock.js` | 개발·테스트용 가상 HID++ 기기 (페이지에서는 불러오지 않음) |
| `js/app.js` | 화면과 상태 관리 |

프로토콜과 프로필 레이아웃은 [libratbag](https://github.com/libratbag/libratbag)의 `hidpp20.c`를 참고했습니다.
