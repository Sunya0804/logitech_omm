G Onboard Memory Manager Web

기기를 연결하세요

Logitech G 마우스의 온보드 메모리에 저장된 프로필(DPI, 보고율, 버튼 할당)을 브라우저에서 바로 읽고 수정합니다.

이 브라우저는 WebHID를 지원하지 않습니다. 데스크톱용 Chrome, Edge 또는 Opera에서 열어 주세요.

  • G HUB나 Logitech Onboard Memory Manager가 실행 중이면 종료한 뒤 연결하세요.
  • 무선 기기는 수신기(동글)를 선택하면 됩니다. 기기 전원이 켜져 있어야 합니다.
  • 변경 내용은 「기기에 저장」을 누르기 전까지 기기에 기록되지 않습니다.
